The installer bundles AutoHotkey64.exe (AutoHotkey v2, GPL-2.0) in this
folder. CI downloads it; for local builds, copy AutoHotkey64.exe and its
license.txt here, or install AutoHotkey v2 normally. KeyForge also looks in
the standard install locations and in the KEYFORGE_AHK environment variable.
Source code for AutoHotkey: https://github.com/AutoHotkey/AutoHotkey
